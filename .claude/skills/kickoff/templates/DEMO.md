# Demo

The 3-minute demo, written first. Everything we build should serve this path; if a
feature isn't on it, it's probably out of scope.

## The pitch in one sentence

_<Who> can <do what> so that <outcome>, which today <is hard because...>._

_The seeded accounts, records and inputs the demo uses, and the script that creates

## Fallbacks

_What we show if the live API, model or network fails: a recorded video, cached
responses, or screenshots._

## Pitch outline (3 minutes)

1. Problem (30s)
2. Demo (2 min)
3. How it works / what's novel (20s)
4. What's next (10s)
